Welcome to my blog. This is my first post, and it's rendered from an MDX file directly inside a retro-styled window.

## Why MDX?

MDX lets me write content in Markdown while embedding React components when needed. It's the perfect format for a developer blog:

- Write naturally in Markdown
- Embed interactive demos
- Keep content in version control
